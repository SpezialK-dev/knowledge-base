# Looking at Mac things on other Systems 

This mostly aims at a Forensic perspective but can be valuable in other situations as well

- [APFS-Fuse](https://github.com/sgan81/apfs-fuse) -> fuse module mounting of apfs disk under linux
- [Unified log paarser](https://github.com/mandiant/macos-UnifiedLogs) -> if one wants to paarse some logs here is tooling for it 
- [Mac APt](https://github.com/ydkhatri/mac_apt) -> allows paarsing of macos and ios artifacts 
- [APPOLO](https://github.com/mac4n6/APOLLO) -> unifies databases on macos
